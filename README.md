# Charleston Caves

Landing page for Charleston Caves — custom private bars, golf rooms, home theaters and garages in Charleston, SC.

Static site: `index.html` plus images in `assets/img/`. No build step.

## Preview locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Before going live

- Replace the placeholder photos in `assets/img/` with full-resolution project photography.
- Fill in `[PHONE]` and `[EMAIL]` in the footer.
- Connect the contact form (currently not wired to anything).
- Confirm the process and materials copy matches how the business actually works.
